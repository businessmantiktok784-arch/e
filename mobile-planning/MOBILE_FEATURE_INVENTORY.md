Endpoints are relative to the server origin; detailed route and error notes are in [`MOBILE_API_INTEGRATION_MAP.md`](MOBILE_API_INTEGRATION_MAP.md). “No” means not supported through the existing mobile-usable API; do not infer a new route.

## Initial release classification

Public explore, observation details, map, community read/write, comments, WhatsApp login, profile, and “My observations/questions” are **READY for API integration / FRONTEND WORK REQUIRED**. Direct in-app capture and AI analysis are a **BACKEND GAP**. Verify actual media availability, database-backed runtime configuration, authentication persistence, and native map tile/style access before release. No feature above authorizes bypassing server checks or exposing Supabase privileged credentials.
